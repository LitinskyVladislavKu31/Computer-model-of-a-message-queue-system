# Computer-model-of-a-message-queue-system
Проект є програмною симуляцією розподіленої черги повідомлень. Його створено для дослідження алгоритмів балансування навантаження у різних мережевих топологіях у рамках магістерської роботи (без застосування класичних систем масового обслуговування).

# Основні можливості
Балансування навантаження: підтримка алгоритмів ROUND_ROBIN, WEIGHTED_ROUND_ROBIN, LEAST_CONNECTIONS, WEIGHTED_LEAST_CONNECTIONS, LEAST_RESPONSE_TIME та IP_HASH.   
Обробка черг: реалізовано стратегії FIFO, LIFO та PRIORITY із функцією динамічного старіння (Aging) для запобігання зависанню повідомлень.   
Мережеві топології: симуляція конфігурацій Star, Ring, Tree, Hypercube та Mesh із користувацькими налаштуваннями обмежень.   
Графічний інтерфейс: налаштування параметрів (кількість вузлів, інтенсивність, втрата пакетів) та візуалізація передачі даних у мережі в реальному часі.   Аналітика: побудова графіків для порівняння середнього часу обробки повідомлень різними алгоритмами.   
Автоматизація: окремий інструмент для пакетного стрес-тестування продуктивності без графічного інтерфейсу.   

# Технології
Мова програмування:Python
Інтерфейс:Tkinter   
Графіки та візуалізація: Matplotlib   

# Структура репозиторія
main.py — головний файл для ініціалізації та запуску програми.   
model.py — ядро симуляції, що містить логіку роботи брокера, воркерів та алгоритмів балансування.   
gui_model.py — реалізація інтерфейсу користувача, відмальовка мережевих графів та керування станом симуляції.   
topology_config.py — параметри, математичні формули та правила валідації для побудови обраних мережевих топологій.   
test.py — скрипт для проведення автоматизованих тестів у консольному режимі.
